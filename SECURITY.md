# Security Policy

## Reporting Security Issues

We take the security and privacy of ARAKNO-AI seriously. If you discover a vulnerability, especially regarding local data isolation, credential leakage, or network exfiltration, please do not open a public issue.

Instead, please send a responsible disclosure report to the repository maintainers with:
- A description of the issue and potential impact
- Steps or a minimal reproduction script
- Suggested remediations if known

## Supported Versions

Only the current `main` branch receives active security updates and patches.
